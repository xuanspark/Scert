# Scert 项目

Scert 是一个统一管理 SSL 证书、自动续期并部署到多台服务器的跨平台项目。

## 正式交付范围

正式产品仅包含 Web 管理界面和 Windows/Linux 服务端。CLI 作为服务端运维入口，用于初始化、服务启动、运维诊断、数据库迁移、备份恢复、服务安装和卸载，不作为另一套业务管理界面。

旧业务 CLI 已停用并返回中文迁移提示，范围和迁移方法见 `doc/命令行运维范围说明.md`。自动续期仍由服务端调度，手动业务操作通过 Web 执行，不再提供绕过 Web 流程的第二套 CLI 入口。

`desktop/` 保留 Wails 历史源码，供参考和独立开发；桌面窗口、托盘、自动更新、桌面配置管理及桌面 UI 测试均不属于正式交付或验收范围。正式发布脚本不调用 Wails，也不需要 WebView2 或 GTK 开发依赖。

## 项目目录

- `backend`：Go 核心服务、CLI、数据库和 HTTP API。
- `frontend`：Vue Web 管理界面。
- `doc`：需求确认、技术架构和开发任务清单。

## 开发基线

- 第一阶段使用 Let’s Encrypt + `go-acme/lego`。
- 第一阶段包含单域名、泛域名和多域名 SAN。
- 数据库支持目标包含 SQLite、MySQL 和 PostgreSQL；版本边界及实机验证状态见 `doc/构建版本与数据库支持矩阵.md`，代码适配不等于真实实例验收通过。
- HTTPS 采用默认核心服务终止、高级反向代理终止的双模式设计。
- Web 和运维 CLI 复用服务端核心、配置和数据。
