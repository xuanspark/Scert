# 测试证据目录

此目录承载按任务、源码提交和日期分组的本地测试输出。除本说明外，内容均不纳入源码提交。

证据至少包含：任务编号、验证层级、源码提交、候选包 SHA256、工具版本、环境标识、执行命令、起止时间、退出码、观察结果及尚未覆盖的项目。

- 自动化、隔离环境、生产实机和复审证据分别归档，不以单一“通过”替代不同层级。
- 对外可复核结论写入 `doc/` 中文记录，并指明证据定位；未上传的本地路径不视为他人已取得证据。
- 原始日志和截图写入前必须脱敏。禁止保存密码、AccessKeySecret、Token、Cookie、SSH/证书私钥、生产数据库导出或含凭据的请求体。
- 数据库备份和主密钥备份应由产品的受保护存储保存，不是本目录的测试附件。
- 验收完成不自动删除历史证据；清理需另外取得授权。
- 临时辅助脚本不能充当验收依据。优先使用正式产品入口、仓库已有测试与原生命令。

目录边界见 `doc/仓库目录与产物边界说明.md`。
