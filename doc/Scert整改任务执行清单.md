## 一、执行规则

1. 代码实现、自动化测试、隔离环境验证和生产验收分开记录。
2. 构建成功、接口返回 HTTP 200 或单元测试通过，不直接等同于生产验收通过。
3. 真实 DNS、ACME、HTTPS、SSH 主机指纹、备份恢复和远程部署必须保留可复核证据。
4. 不使用 `-k`、`--insecure`、跳过 SSH 主机指纹或强制 IP TLS 的方式替代正式验证。
5. 不将密码、RAM 密钥、Token、私钥、真实证书或 Cookie 写入代码、文档、日志和 Git。
6. 每个任务完成后先标记为 `[x]`，复审和对应范围的验收证据齐全后才能标记为 `[✓]`。
