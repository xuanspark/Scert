## 三、迁移与降级边界

1. 三种数据库必须提供相同编号和名称的迁移，SQL 内容允许因方言不同而不同。
2. `migration_catalog_test.go` 检查源码目录、嵌入资源和 `latestMigrationVersion`；新增文件忘记登记或嵌入时必须失败。
3. `Migrate` 在执行后续迁移前读取完整有序版本历史；版本高于程序支持范围或历史不连续时拒绝启动，不自动删除或修补版本记录。
4. MySQL 的 DDL 重入和 PostgreSQL 的事务回滚必须用对应引擎验证，不能通过文件数量一致推断行为一致。
5. 当前不存在通用向下迁移承诺。降级须使用兼容程序及对应已验证备份，在隔离环境验证后再操作，禁止通过删除 `schema_migrations` 绕过拒绝。

## 四、真实实例验收步骤

每个数据库和声明支持的服务端版本独立执行以下步骤，保存版本、候选提交、命令退出码和脱敏证据：

1. 建立明确归属的隔离空库和最小权限账户，验证 TLS 与主机身份；不使用现有业务库。
2. 按正式初始化入口完成配置；创建用户、域名、DNS 账户、服务器和任务，验证权限隔离。
3. 从支持的旧版本数据库升级，检查数据、索引、默认值、归属和任务状态；重复执行不产生额外变更。
4. 注入迁移中断，在恢复后确认重入/回滚；新版数据库被旧程序拒绝且原数据保持不变。
5. 按该数据库的 CLI 备份恢复流程在另一隔离空库恢复；验证敏感配置和证书关联，篡改备份必须拒绝。
6. 重启服务验证持久化，完成前后端业务回归；记录未执行、跳过和失败项，不汇总为通过。

MySQL/PostgreSQL 没有当前实机证据的格子保持待验收。本矩阵不授权清理共享数据库或同机其他服务。

## 六、MySQL 在线连接池恢复

正式入口：`backend/internal/database/mysql_recovery_integration_test.go`；复用第五节隔离夹具。两个版本分别设置程序目录后运行：

```powershell
go test -count=1 -v -timeout=8m -run '^TestMySQLReal(Migrations|PoolRecovery)$' ./internal/database
```

实现和行为边界：

1. 锁定的 MySQL 驱动在 Windows 上没有有效的空闲套接字检查。复用连接之前通过驱动的 `SessionResetter` 增加一次有界 `COM_PING`；Linux 保留驱动原有检查，不增加这次往返。
2. 单次探测最多 2 秒；调用者更短的截止时间或取消优先。探测失败关闭连接并返回 `driver.ErrBadConn`，让连接池在发送业务语句之前更换连接。
3. 完整保留驱动的查询、写入、预编译、事务、参数转换和连接校验接口。不包装业务执行及提交错误，不新增 SQL 或事务重放逻辑。
4. `checkConnLiveness` 默认开启；显式关闭时不启用上述额外检查，不保证失效空闲连接上的首次请求成功。连接仍可能在探测成功后断开，应用必须处理执行错误及提交结果不确定性。
5. 成本是 Windows 每次复用池连接时增加一次协议往返；同一已取得的事务连接内部不重复探测。当前没有远距离网络性能基准，不以 loopback 测试推断生产延迟。

新增 7 个实库场景每个使用单独业务库：保留旧池并重启数据库后的首次写入、空闲断线后的预编译语句、首次查询及迁移、无符号整数参数及正常提交、只读事务与正常回滚、活动事务连接中断、数据库不可用时有界失败并恢复。每次故障后的数据值均验证，避免把重复写入或未提交数据当作恢复成功。

`mysql_pool_test.go` 另行验证健康探测、驱动拒绝、探测失败、截止时间、取消、写入前更换连接，以及查询、写入和提交响应不确定时保留原错误且不重放。响应丢失场景是驱动接口层故障注入，不声称已完成真实网络丢弃提交确认包的演练。

候选 `9cf3a3b` 在 Windows 的 MySQL 5.7.44、8.0.45 均为 55 项子测试通过，0 失败、0 跳过。产物位于 `artifacts/mysql-matrix-20260927/mysql57-9cf3a3b.log` 和 `mysql80-9cf3a3b.log`，不纳入源码。Linux 数据库测试包交叉编译通过，但没有执行 Linux 实库恢复；其门禁仍然保留。

## 七、MySQL 基本备份恢复与指定失败回滚

候选 `7bfd400`；正式入口为 `backend/internal/cli/mysql_integration_test.go` 和 `mysql_commands_integration_test.go`，复用严格 TLS、随机账户、全新实例的共享夹具。

修复前在 5.7.44 的真实数据库上复现两类错误：禁用空闲连接后，会话变量跨 SQL 语句丢失；DECIMAL 文本字节被作为十六进制数值恢复，出现数值越界。修复固定恢复连接，并依据字段类型导出精确文本；旧 DECIMAL 备份没有自动转换，应重新生成并验证备份。

新增测试覆盖：

1. `MaxIdleConns=0` 时，记录并比较同一恢复脚本中的真实连接编号。

### 实现与复现

1. 备份枚举表、读取表结构和数据使用同一只读可重复读事务。数据快照在首次一致性读取时建立，不声称事务开始瞬间已建立快照；外部并发 DDL 仍须禁止。

4. 该限制针对单次元数据锁获取，不是整个备份的 5 秒执行期限，不为任意查询、多个锁等待或任意网络故障承诺统一取消完成时间。备份遇到锁超时直接失败，不重放事务；维护期间需要排除外部 DDL。
