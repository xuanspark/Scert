# Scert 后端接口说明文档

> 本文档用于完整说明 Scert 证书管理系统当前所有 HTTP API 路由、请求参数、返回契约及权限约束。
> 核对基准：当前代码分支 main（版本：1.52.5）。

---

## 1. 架构原则与通用调用约定

### 1.1 基础地址与反向代理
- 生产环境默认管理地址：https://odacm.cn
- 服务默认本地监听：127.0.0.1:8080（通过 Nginx 进行 TLS 终止及反向代理）

### 1.2 认证模式与安全边界
1. **会话认证（Session-Based）**：
   - 登录成功后通过 Set-Cookie 写入 HttpOnly 会话凭据 scert_session。
   - 所有写入请求（POST / PUT / DELETE）均经过同源保护检查（Same-Origin Check），严格校验 Origin 与 Referer。
2. **三级权限控制**：
   - **普通用户（user）**：仅可访问被授权参与的项目、查看项目内域名/服务器/证书、发起证书申请与部署。
   - **管理员（admin）**：具备其管理分组/项目范围内的成员管理、项目资源调配权限，可查看全局只读统计。
   - **超级管理员（super_admin）**：拥有全局最高权限，唯一具备系统配置（SMTP、默认 DNS 凭据、续期策略）、用户账号增删改查权限。
3. **敏感凭据脱敏**：
   - DNS AccessKeySecret、SSH 登录密码等敏感数据入库加密，查询接口一律返回脱敏标识（如掩码或布尔指示），禁止明文泄露。

### 1.3 统一响应契约
所有 JSON 接口统一遵循以下响应规范：
- 200 OK / 201 Created：请求成功处理。
- 400 Bad Request：参数校验未通过或业务前置条件不满足。
- 401 Unauthorized：未登录或会话已过期。
- 403 Forbidden：权限不足（如非超管访问系统设置）。
- 404 Not Found：请求资源不存在。
- 409 Conflict：资源冲突（如域名/账号已存在）。
- 500 Internal Server Error：服务端内部异常。

## 2. 系统初始化接口 (Bootstrap API)

在系统首次启动且未完成向导配置时生效，初始化完成后自动关闭。

| 方法 | 路径 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| GET | /readyz | 公开 | 就绪状态探针，返回服务初始化状态及就绪信息 |
| GET | /healthz | 公开 | 健康检查探针 |
| GET | /api/v1/setup/status | 公开 | 获取当前向导初始化进度、数据库驱动及支持清单 |
| GET | /api/v1/setup/dns/providers | 公开 | 获取支持的 DNS 服务商列表（如 Aliyun） |
| POST | /api/v1/setup/dns/test | 初始化临时会话 | 测试 DNS 服务商凭据连通性与 API 权限 |
| POST | /api/v1/setup | 初始化临时会话 | 提交并应用系统首次初始化配置（超管、数据库、凭据） |

## 3. 认证与会话管理 (Auth API)

| 方法 | 路径 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| GET | /api/v1/status | 公开 | 获取系统运行时状态与版本号（如 v1.52.5） |

| POST | /api/v1/auth/password | 已登录 | 修改当前已登录账号的登录密码 |
| POST | /api/v1/password-reset/resolve | 公开 | 密码重置指引接口（本地 IPC 引导保护） |

## 4. 用户与权限管理 (Users API)

仅超级管理员具备用户完全管理权限；普通用户与管理员受限于其组织权限。

| 方法 | 路径 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| GET | /api/v1/users | 已登录 | 获取系统用户列表（普通用户受限查看） |
| POST | /api/v1/users | 超级管理员 | 创建新用户（支持设置账号名、密码、邮箱、初始角色） |
| GET | /api/v1/users/:id | 已登录 | 获取指定用户的详细资料 |
| PUT | /api/v1/users/:id | 超级管理员 | 更新指定用户的账号状态、所属角色或重置密码 |
| DELETE | /api/v1/users/:id | 超级管理员 | 删除指定用户（主超级管理员不可删除） |

## 5. 项目与成员协作 (Project Management API)

支持多项目隔离管理，项目可独立绑定成员、域名、DNS 凭据和部署服务器。

| 方法 | 路径 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| GET | /api/v1/projects | 已登录 | 获取当前账号可见的项目列表（分页） |
| POST | /api/v1/projects | 超管 / 权限账户 | 创建新项目（填写项目名称、项目说明） |
| PUT | /api/v1/projects/:projectID | 项目管理员 | 修改项目资料（更新名称与说明） |
| DELETE | /api/v1/projects/:projectID | 项目管理员 | 删除项目（默认项目不可删除，有资产关联时不可删除） |
| GET | /api/v1/projects/:projectID/members | 项目成员 | 查询指定项目的成员列表及被赋予的项目角色 |
| POST | /api/v1/projects/:projectID/members | 项目管理员 | 为项目成员授予角色（项目管理员、普通操作者、只读用户） |
| DELETE | /api/v1/projects/:projectID/members/:userID/roles/:role | 项目管理员 | 撤销成员在项目中的指定角色 |
| GET | /api/v1/audit-logs | 已登录 | 查询当前项目与全局的操作审计流水 |

## 9. 异步任务与执行审计 (Tasks API)

证书的签发、远程推送部署、回环 HTTPS 校验均为异步任务执行引擎驱动。

| 方法 | 路径 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| GET | /api/v1/tasks | 项目授权 | 获取异步任务列表（支持按域名、任务类型、状态过滤） |
| GET | /api/v1/tasks/:id | 项目授权 | 获取指定任务的当前阶段、执行状态、结果消息 |
| DELETE | /api/v1/tasks/:id | 项目授权 | 取消处于等待中（pending）或运行中的任务 |
| POST | /api/v1/tasks/:id/retry | 项目授权 | 对执行失败（failed）的任务发起重新执行 |
| GET | /api/v1/tasks/:id/attempts | 项目授权 | 查询该任务的所有执行尝试流水记录与重试日志 |
| GET | /api/v1/tasks/:id/deployment-results| 项目授权 | 查询部署任务针对各台目标服务器的详细推送结果与执行状态 |
| GET | /api/v1/tasks/:id/validation-results| 项目授权 | 查询证书校验任务对各节点的 HTTPS 握手与证书链详细诊断数据 |

| :--- | :--- | :--- | :--- |
| GET | /api/v1/settings | 超级管理员 | 获取系统全局配置（邮件通知设置、默认 DNS、证书续期策略） |
| PUT | /api/v1/settings | 超级管理员 | 保存/更新系统配置（分项独立更新） |
| POST | /api/v1/dns/test | 超级管理员 | 验证系统默认 DNS API 凭据连通性 |
| POST | /api/v1/notification/test | 超级管理员 | 实时测试 SMTP 邮件发信连通性，发送测试邮件验证配置 |
| POST | /api/v1/dns/aliyun/check | 超级管理员 | 深度校验阿里云 RAM 凭据对特定域名的操作授权（解析记录读写权） |
