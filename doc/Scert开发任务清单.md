## 二、已确认的需求基线

### 2.1 项目和平台

- [x] 项目名称为 `Scert`。
- [x] 支持 Windows 和 Linux。
- [x] 目标构建架构为 amd64。
- [x] 基础测试范围为 Windows 10/11、Ubuntu 22.04 + Nginx。
- [x] 扩展测试范围为 Ubuntu 24.04 + Nginx、CentOS/Rocky Linux、Debian、Caddy、Apache 和其他主流反向代理。
- [x] Linux systemd 以 Ubuntu 22.04 默认版本作为最低兼容基线。
- [x] 提供命令行版本、Web 管理界面和 Wails 桌面版。
- [x] CLI、Web 和桌面版共享同一套核心服务、配置和数据库。

### 2.2 工具链基线

- [x] Go：`go1.26.2`。
- [x] Node.js：`v24.19.0`。
- [x] npm：`11.17.0`，Windows PowerShell 中优先使用 `npm.cmd`。
- [x] Wails：`v2.11.0`。
- [x] 编写代码时使用英文标识符。
- [x] 注释、说明、文档和界面显示使用中文。

### 2.3 ACME 和证书

- [x] 第一阶段使用 Let’s Encrypt。
- [x] 使用 `go-acme/lego`，不使用 `acme.sh`。
- [x] 支持 Let’s Encrypt Production 和 Staging。
- [x] 支持 DNS-01 验证。
- [x] 第一阶段支持单域名、泛域名和多域名 SAN 证书。
- [x] SAN 证书以主域名作为管理归属。
- [x] 保存完整 SAN 域名集合。
- [x] SAN 集合变化时生成新的证书标识和证书版本。
- [x] 续期失败时保留原证书，避免服务中断。

### 2.4 DNS 验证

第一阶段 DNS 验证适配范围：

- [x] Cloudflare。
- [x] 阿里云 DNS。
- [x] DNSPod。
- [x] CNAME 委派。
- [x] 华为云。
- [x] 腾讯云。
- [x] AWS Route 53。
- [x] Google Cloud DNS。
- [x] 预留其他 DNS 服务商扩展接口。

### 2.5 数据库

- [x] 支持 MySQL 5.7。
- [x] 支持 MySQL 8.0。
- [x] 支持 SQLite。
- [x] MySQL 5.7 作为基础开发和最低兼容版本。
- [x] MySQL 8.0 作为兼容性测试版本。
- [x] SQLite 用于单机、桌面版和开发测试模式。
- [x] 使用 `database/sql` 和 Repository 数据访问层。
- [x] MySQL 与 SQLite 分别维护迁移脚本和方言适配。
- [x] 不通过 PATH 中的单个 `mysql` 命令判断版本。

本机 MySQL 客户端版本记录：

| 安装路径 | 版本 | 用途 |
|---|---|---|
| `E:\DB\5.7\bin\mysql.exe` | MySQL 5.7.44 | 基础开发和最低兼容性验证 |
| `E:\DB\8.0\bin\mysql.exe` | MySQL 8.0.45 | 兼容性测试 |

### 2.6 HTTPS 模式

- [x] 默认模式：核心服务直接终止 HTTPS。
- [x] 高级模式：Nginx/Caddy 终止公网 HTTPS，核心服务使用内部 HTTPS。
- [x] 初始化期间允许 HTTP。
- [x] 初始化完成后管理后台强制使用 HTTPS。

### 2.7 通知边界

- [x] 支持 HTTP API 通知。
- [x] 支持 SMTP 出站客户端通知。
- [x] Scert 不实现 SMTP、IMAP、POP3 邮件服务器端。
- [x] SMTP、IMAP、POP3 协议表仅作为外部邮件服务兼容性参考。
- [x] HTTP 通知支持自定义地址、Bearer Token、HMAC-SHA256、无认证、详细事件、统一事件、自定义请求头、完整部署明细、证书序列号、管理后台链接、2xx 成功判断和可配置重试。

### 2.8 默认目录

Linux：

```text
证书：/ssl
安装：/scert
配置：/scert/conf
日志：/scert/log
备份：/scert/backups
```

Windows：

```text
证书：{安装目录}\Scert\ssl
数据库：{安装目录}\Scert\data
配置：{安装目录}\Scert\config
日志：{安装目录}\Scert\logs
备份：{安装目录}\Scert\backups
```

## 三、开发原则和边界

- [ ] 不在第一轮基础骨架中虚构证书申请已经完成。
- [ ] 不在未完成验证前宣称 DNS Provider 已经可用。
- [ ] 不在未完成远程测试前宣称多服务器部署完成。
- [ ] 所有长任务使用持久化任务记录。
- [ ] 所有证书操作保留审计日志。
- [ ] 所有敏感信息必须加密保存或脱敏处理。
- [ ] 续期和部署失败时保留旧证书。
- [ ] 安装、升级和卸载不得删除用户证书、数据库和备份。
- [ ] 远程命令必须经过白名单或严格格式校验。
- [ ] 不把用户输入直接拼接为 Shell 命令。
- [ ] 不把数据库连接信息、Token、密码和私钥写入 Git。
- [ ] 不未经用户同意删除任何文件。
- [ ] 不未经用户明确要求提交或推送 Git。
