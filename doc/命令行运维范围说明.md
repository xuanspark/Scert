# 命令行运维范围说明

## 一、正式范围

依据《Scert整改合并优化清单》P0-01，正式产品为 Web 管理页面和 Windows/Linux 服务端。CLI 是本机运维入口，不再维护另一套域名、服务器或凭据业务管理界面。

| 入口 | 用途 | 边界 |
|---|---|---|
| `version`、`help` | 版本和中文帮助 | 不启动业务服务 |
| `init` | 首次配置初始化 | 仍执行初始化参数、凭据和防火墙检查 |
| `serve` | 启动正式服务及首次初始化入口 | 定时续期由服务端生命周期管理 |
| `status` | 本机状态诊断 | 不替代公网 HTTPS 或生产验收 |
| `certificate list/show/validate` | 查询现有证书及校验 | 不提供申请、导入、续期或部署操作 |
| `logs` | 本机日志诊断 | 不替代完整审计中心 |
| `config` | 本机配置诊断及受限配置调整 | 保留现有字段白名单，不允许直接写入密码摘要 |
| `dns check` | 指定域名的 DNS 权限诊断 | 保留写入确认、保护域和精确清理限制，不能擅自执行真实 DNS 测试 |
| `backup`、`restore` | 停服备份恢复及数据库维护 | 仍须校验维护锁、备份完整性、凭据、数据库版本及失败回滚 |
| `service` | 注册、卸载、启停系统服务 | 必须遵循目标平台权限及安装要求 |
| `scert-admin` | 超级管理员密码恢复 | 继续使用受保护本机 IPC，不开放公网重置接口 |

数据库迁移仍由现有初始化/应用加载路径执行，本次没有新增独立 `migrate` 命令；该说明不意味着三种数据库的实机迁移已经验收。

## 二、停用的业务入口

以下一级命令不再出现在默认帮助中，也不会执行原有操作：

- `domain`：域名增删改查、证书申请或导入、服务器关联等。
- `server`：部署服务器管理。
- `ssh-key`：部署私钥管理。
- `renew`：手动续期或触发续期检查。
- `deploy`：手动证书部署。

调用旧命令时返回非零退出状态及中文提示，要求使用 Web 管理页面。拒绝发生在读取配置、凭据或数据库之前，不尝试建立 SSH、DNS 或 ACME 连接，不输出旧参数中的密码。旧子命令和参数不会恢复原行为。

旧命令实现文件暂时保留以保存历史和已有回归测试，但正式命令树不再注册这些实现；不以隐藏帮助代替停用执行。

## 三、迁移方法

1. 保留用于启动服务、查看状态、诊断、备份恢复及平台服务管理的现有运维流程。
2. 停止依赖旧业务命令的定时任务和自动化调用，避免非零退出被误当成成功。
3. 在 Web 中管理域名、DNS 账户和服务器密码凭据，发起手动申请、续期、导入及部署；不提供 SSH 私钥、公钥或密钥登录配置。
4. 自动续期继续由服务端执行，不需要额外配置 `scert renew` 定时任务。

这次变更只收敛 CLI 入口，不代表 Web 的统一任务中心、项目隔离、完整审计或生产门禁已全部完成；这些仍按对应整改项执行。

## 四、验证要求

- 根命令树只公开范围内运维入口，默认帮助不列出停用命令。
- 旧命令包含原有参数、无效配置或模拟凭据时，都在访问数据前拒绝；不改动配置、不新建运行数据、不回显凭据。
- 保留证书诊断、DNS 诊断、配置、备份恢复、初始化和服务管理测试。
- 从实际构建的可执行文件检查帮助与旧入口退出码；单元测试不替代发布产物验证。
