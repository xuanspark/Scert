## 2026年10月4日07:40 DNS 执行与原子绑定契约

- MySQL 迁移恢复必须拒绝表级和列级排序规则冲突；故障测试必须先确认注入后的规则确实不同，不能使用库的默认值伪造冲突场景。该修正不改变产品迁移规则。
- 授权探测同样可能写临时 TXT，每个域名调用前必须核验取消状态和真实租约。探测错误无法确认外部清理时保留引用，即使 ACME Provider 尚未创建；之后的成功探测不得清除先前未知状态。
- 新建域名可携带 `dns_account_id`、`dns_account_revision`；绑定标识由服务端生成，域名、绑定、审计共用事务。普通资料更新拒绝这些初始绑定字段，编辑仍使用独立绑定接口及真实旧令牌。
- 租约绑定真实运行中的任务、尝试、序号、项目、域名、账户版本及秘密引用。自动续期必须同时满足服务端调度标记、真实无操作者续期任务和域名启用续期；手工重试额外要求重试权限。
- 获取租约在域名行锁内比较完整签发配置，不依赖秒级时间戳；SAN 按实际数组比较。活动租约阻止账户变更、绑定切换及两层域名资料更新/删除，证书状态更新不受影响。
- DNS 写入前重新授权，清理使用原 Provider 和固定凭据、独立超时；任务取消不得跳过清理。不按 TTL 或任务终态释放未知外部状态的引用，释放失败保持租约。
- 接口租约忙返回 409，不暴露随机租约能力或秘密引用。遗留租约外部核对与安全回收尚未实现；当前契约的本地测试不能替代真实 DNS/ACME 及三库生产验收。
