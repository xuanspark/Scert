# 本机部署核查使用说明

## 当前发布状态

2026年10月3日：功能正在原生 Linux 验证，尚未随正式候选包部署。以下说明适用于包含该功能的新版本，不能据此认定线上已经提供此菜单。

## 入口与权限

在 Scert 所在 Linux 主机的管理员交互终端执行：

```bash
systemctl start Scert-admin
```

主服务必须已初始化并正常运行。本机管理员工具仍通过既有受保护的 Unix socket 通信，保留目录、权限和对端身份校验；不开放 HTTP 恢复接口，不增加 TCP 监听。密码重置仍必须通过绑定邮箱验证码，不因核查功能而跳过验证。

## 只读核查步骤

1. 在本机管理菜单输入 `2`，进入只读部署事务核查。
2. 每页最多显示五条待处理或需要恢复的事务，包含事务标识、服务器标识、阶段、状态和历史证据是否存在。
3. 输入 `n` 翻页，输入本页序号核查对应事务，输入 `q` 退出。
4. 核查结果显示目标文件、临时文件、备份文件的存在性与摘要比较，以及锁的存在性和归属判断。不显示证书内容、密码、私钥或锁令牌。
5. 一次核查完成后退出。若需要继续处理其他事务，重新启动本机管理员工具。

会话有效期为两分钟，每个会话最多处理三十二次核查请求；列表查询最多五秒，现场核查最多三十秒，并遵守更短的调用方期限。每个消息帧限制为十六 KiB，超限结果拒绝返回，不截取部分内容冒充完整核查。

## 结果边界

- 核查只读，不执行远端命令、不写文件、不建立或删除锁、不提交或回滚事务。
- 列表分页和现场读取都不是数据库或远端文件的一致性快照，其他操作可能同时改变现场。
- “历史证据已保存”仅说明记录存在，不代表部署已经通过生产验收；缺失的历史证据不会补造。
- 摘要匹配不等于 Nginx 重载成功，也不等于公共 HTTPS、SNI 或业务流量已经验证通过。
- 输入异常、过期、读取失败、响应超限或管理员配置发生变化时，终止会话，不将部分观察作为成功结果。
- 核查与密码重置不能在同一会话互相切换；需要切换时退出后重新启动。

## 尚未提供的能力

独立人工处置、审计和基于可信证据的提交或回滚仍在开发。不要手工修改数据库事务终态，不要删锁后宣称历史部署成功。完整状态以整改清单和生产测试记录为准。
