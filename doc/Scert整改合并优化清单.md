## 一、整改目标

将 Scert 整改为一个具备以下能力的 Web 化 SSL 证书运维平台：

1. 证书申请、导入、续期、部署、回滚统一管理。
2. 支持 ACME、Let’s Encrypt、DNS-01、泛域名和 SAN 证书。
3. 支持 DNS 账户、CNAME 委派和 DNS 验证记录管理。
4. 支持多服务器、多部署目标和远程证书部署。
5. 支持任务调度、失败重试、任务日志和执行历史。
6. 支持通知、审计、监控、备份和恢复。
7. 支持用户、角色、项目和资源级权限隔离。
8. 支持 Windows Service 和 Linux systemd 部署。
9. 所有敏感凭据、SSH 主机身份和证书私钥均具备安全保护。
10. 所有生产能力都有独立的实机验收证据。
