## 四、代码变更与使用方式

### 只读检查

```bash
scert dns inspect --domain example.com --config /scert/conf/scert.json
```

- 只调用指定托管区的 `DescribeDomainRecords`，单页一条，不输出业务记录内容。
- 不逐级检查父域，不调用全局发现，不执行新增、更新、删除。
- 读取成功时退出码为零，但 `verified=false`；报告明确表示未验证写入和清理权限。
- 云端拒绝或网络失败退出非零。网络失败不得被解释为已确认权限拒绝。

### 明确授权后的临时写入检查

```bash
scert dns check --domain example.com --confirm-dns-write --config /scert/conf/scert.json
```

- 未提供 `--confirm-dns-write` 时，在读取凭据和发起云端调用之前拒绝。
- 复用项目原有 `AliyunAuthorizationChecker.Verify`，不使用成功缓存冒充实时证明。
- 原有检查器可能针对子域逐级尝试父托管区；实际验收本轮只传入已明确允许检查的根域。
- 不启动应用、续期任务、通知服务或业务数据库，不改写初始化状态，也不申请或部署证书。
- 主密钥或密文存储文件缺失时拒绝，不通过自动生成新主密钥掩盖凭据损坏。
