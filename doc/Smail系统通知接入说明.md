# Smail 系统通知接入说明

初始化向导仅配置 SMTP 连接、系统通知凭据和通知收件人，不再显示自定义发件人名称、发件人地址及通知页底部的密码重置地址说明条。

## 使用方式

1. 在 Smail 的系统通知页面启用对应账号的发信授权，并获取连接参数和独立发信凭据。
2. 将该页面提供的 SMTP 主机、端口、连接模式和完整用户名填入 Scert。用户名格式为 `notify:账号@邮件主域名`，密码栏填写系统通知专用凭据，不是普通登录密码。
3. Scert 自动使用 `notification+system@邮件主域名` 作为发件地址，显示名称固定为“系统通知”。不要从 SMTP 主机名或 Scert 管理域名猜测邮件主域名，应原样使用 Smail 给出的用户名。
4. 通知收件人单独配置；管理员邮箱不再作为 SMTP 默认发件人。未填写通知收件人时仍沿用管理员邮箱作为收件人。

## 兼容与安全边界

- Smail 系统通知身份优先于历史自定义发件人配置。普通 SMTP 配置仍保留兼容能力；未设置发件地址时只能使用完整邮箱形式的 SMTP 账号，不能回退为管理员邮箱。
- 已有 HTTP 通知配置保留兼容，不在初始化向导恢复 HTTP 入口。
- 密码重置安全邮件仍只发往绑定邮箱；隐藏说明条不改变受保护的重置流程。
- 凭据仍进入加密存储，不写入正式配置或文档。保留 TLS 校验，不为发信测试关闭认证或证书校验。
- 本说明描述接入规则，不代表真实 Smail 认证、投递及收件箱验收已完成；协议单元测试不能代替生产实发。
