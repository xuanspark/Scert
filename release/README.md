# 发布包目录

此目录用于存放准备分发的 Web 与 Windows/Linux 服务端候选包。除本说明外，内容均由仓库级忽略规则排除，不纳入源码提交。

- 正式入口为 `build/build-release.ps1`，可通过 `-OutputDirectory` 指定本目录下新的唯一子目录。
- 构建中间文件默认仍位于 `build/`；既有输出不删除、不覆盖，也不必为统一目录而移动历史文件。
- 每份候选包应具有源码提交、版本、目标平台、`manifest.json` 和 SHA256 校验记录。正式候选要求 `source_dirty=false`。
- 不打包 `.runtime/`、数据库、用户配置、凭据、私钥、浏览器缓存、历史桌面产物或验收证据。
- 包内证书、配置示例只能来自明确的发布白名单，不得从正在运行的服务器复制配置作为模板。
- 发布前按 `doc/Scert整改任务执行清单.md` 对应版本完成门禁。包能构建、解压或启动不等于生产验收通过。

目录边界与现有文件保留规则见 `doc/仓库目录与产物边界说明.md`。
